# Practical 1 — MERN Environment Setup
This folder is a ready starter setup. Install Node.js LTS and MongoDB Community Server (MongoDB is needed from P3 onward).
Open two terminals:
1. Backend: `cd backend` → `npm install` → `npm run dev`
2. Frontend: `cd frontend` → `npm install` → `npm run dev`
Frontend opens the Vite URL shown in terminal. Backend runs on port 5000.
